# Evidence Checklist

This folder describes evidence to capture after running the project. Generated reports stay under `reports/` and are ignored by Git until deliberately selected and reviewed.

Recommended filenames:

- `01-fastapi-endpoints.png`
- `02-n8n-workflow.png`
- `03-baseline-pass-report.png`
- `04-candidate-fail-report.png`
- `05-regression-comparison.png`
- `06-controlled-hallucination-detected.png`
- `07-sqlite-run-history.png`
- `08-github-actions-success.png`

Before committing screenshots, crop unrelated applications, browser accounts, bookmarks, file paths containing private names, and any credentials.
